# MatrixZeroAnalyzer



## Назначение

Консольная программа для анализа квадратных вещественных матриц n x n.

Считает количество нулевых элементов выше и ниже главной диагонали,

а также выше и ниже побочной диагонали.



## Требования к окружению

- Python 3.10 или выше

- Git



## Запуск (предварительная инструкция)

Выполнить в терминале команду:



&#x20;   python src/matrix\_zero\_analyzer.py



Затем ввести размерность n и элементы матрицы построчно через пробел.
