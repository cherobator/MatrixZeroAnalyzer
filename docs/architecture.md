# Архитектура MatrixZeroAnalyzer

## Модули
- `src/matrix_zero_analyzer.py` — основной модуль:
  - `read_matrix()` — ввод размерности n и построчный ввод элементов, перевод в float;
  - `count_zeros(matrix)` — обход матрицы во вложенных циклах, подсчёт нулей
    выше/ниже главной и побочной диагоналей;
  - `main()` — вывод исходной матрицы и результатов.
- `src/report.py` — `format_report()` формирует текстовый отчёт.
- `tests/` — автоматические тесты (pytest).

## Поток данных
Ввод n и матрицы → count_zeros → кортеж из 4 счётчиков → вывод отчёта.

## Условия областей
- Главная диагональ: i = j; выше: j > i; ниже: i > j
- Побочная диагональ: i + j = n - 1; выше: i + j < n - 1; ниже: i + j > n - 1
