# MZA-001 — модуль ввода принимает NaN и бесконечности

- Модуль — `src/input_module.py`, функция `create_matrix_payload`.
- Тяжесть — средняя.
- Приоритет — средний.
- Статус — исправлен и проверен повторным запуском.

## Шаги воспроизведения

1. На версии до исправления вызвать `create_matrix_payload([[float("nan")]])`.
2. Повторить вызов с `float("inf")` и `float("-inf")`.
3. Для автоматической проверки запустить `python -m pytest -v tests/test_non_finite_input.py`
   с тестом воспроизведения.

## Ожидаемый результат

Функция отклоняет каждую из трёх матриц с исключением `ValueError`.

## Фактический результат до исправления

Функция принимала все три матрицы. Pytest зафиксировал три результата
`DID NOT RAISE ValueError`.

## Исправление и повторная проверка

После преобразования числа в `float` функция проверяет его с помощью
`math.isfinite()`. Повторный запуск прошёл для всех трёх входов. Полный
набор из 69 тестов также прошёл.
