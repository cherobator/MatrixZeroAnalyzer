# Инспекция кода интеграции

## Способ проверки
Самостоятельная инспекция исходного кода, статическая проверка
flake8 и автоматическое тестирование pytest.
Проверены интерфейсы, преобразования данных, бинарный формат,
обработка ошибок и ограничение времени работы.

## Обнаруженные и исправленные замечания
- В format_mapped_report отсутствовал возврат готового отчёта.
  Добавлен возврат заголовка и результатов анализа.
- В input_module.py обнаружены W293 и W292:
  пробелы на пустой строке и отсутствие завершающего перевода строки.
  Оформление исправлено.

## Проверка взаимодействия
- Поля анализа явно сопоставляются полям отчёта.
- Бинарный файл проверяется по сигнатуре, версии и размеру.
- Повреждённые данные и неизвестные версии отклоняются.
- Недоступность импортируемого модуля преобразуется в RuntimeError.
- Ошибки входных данных передаются как ValueError.
- Превышение времени ожидания преобразуется в TimeoutError.
- subprocess.run при таймауте завершает дочерний процесс
  и дожидается его остановки.
- Защищённый запуск отклоняет NaN и бесконечности.
- Ошибки запуска процесса и некорректный JSON-ответ обработаны.

## Границы проверки
Покрытие измерено для строк модулей src.
Код WORKER хранится в строке и выполняется отдельным процессом:
его внутренние строки не учитываются как обычные строки модуля.
Поведение дочернего процесса проверено отдельными сценариями
успеха, ошибочных данных, отсутствующего модуля и таймаута.
Непокрыты преимущественно демонстрационные функции main
и ветка ограничения максимального размера при записи.
