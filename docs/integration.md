# Интеграция MatrixZeroAnalyzer

## Вариант
Вариант 6. Сохраняется задача из ЛР 1–2:
подсчёт нулей относительно диагоналей квадратной матрицы.
Стратегия — Т-образная. Протокол — обмен через бинарный файл.
Бинарный обмен будет реализован на уровне 2.

## Стратегия и обоснование
Сначала реализован простой сквозной сценарий через все слои:
ввод, анализ, формирование результата.
Затем расширены проверки входных данных и граничных случаев.
Это позволяет проверить совместимость всей цепочки,
после чего последовательно расширять возможности системы.

## Модули
- input_module.py — проверка и нормализация матрицы.
- matrix_zero_analyzer.py — подсчёт нулевых элементов.
- report.py — формирование текстового результата.
- integration.py — управление цепочкой вызовов.

## Схема интеграции
Матрица
  -> create_matrix_payload(matrix)
  -> словарь входных данных
  -> analyze_payload(payload)
  -> словарь результатов
  -> преобразование в кортеж четырёх счётчиков
  -> format_report(counts)
  -> текстовый результат.

Последовательность выполняется функцией run_pipeline.
На уровне 1 используются прямые вызовы функций.
Все модули доступны, поэтому заглушки не потребовались.
Демонстрационный запуск выполняет функция main.

## Интерфейсы
create_matrix_payload принимает квадратную числовую матрицу.
Возвращает protocol_version, matrix_size и matrix_data.

analyze_payload принимает словарь входных данных.
Возвращает dim, zeros_above_main, zeros_below_main,
zeros_above_secondary и zeros_below_secondary.

format_report принимает кортеж из четырёх счётчиков.
Порядок: выше главной, ниже главной,
выше побочной, ниже побочной диагонали.
Результат — строка с текстовым отчётом.

## Обработка ошибок
Модуль ввода отклоняет пустую и неквадратную матрицу,
строковые и логические элементы с исключением ValueError.
Функция main перехватывает ValueError, TypeError и KeyError
и выводит сообщение об ошибке.
