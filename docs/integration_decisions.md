# Решения по интеграции

## Согласованный протокол
Формат обмена: MZA1, заголовок 9 байт, элементы float64.
Версия протокола: 1. Неизвестные версии отклоняются.

## Моделирование конфликта
В ветках feature/binary-exchange и feature/protocol-review
независимо создан файл docs/integration_decisions.md
с различающимся содержимым.

При слиянии возник конфликт add/add.
Одна версия описывала проверку версии протокола,
другая — структуру бинарного формата.

При разрешении сохранены оба совместимых положения,
маркеры конфликта удалены.
