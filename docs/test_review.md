# Самостоятельное ревью тестов

Проверены ясность сценариев, независимость тестовых данных и точность
ожиданий. В тестах анализа используются разные значения всех четырёх
счётчиков, чтобы выявлять перестановку полей. Интеграционный сценарий
сравнивает три пути запуска с явно заданным отчётом.

Тесты бинарного обмена используют `tmp_path`. Регрессия MZA-001
проверяет исключение и сохранение ранее записанного файла при
ошибочном вводе. В случаях с NaN и бесконечностями проверяется причина
отказа по тексту исключения.

Замечание ревью — pytest включал экранированные русские строки
в названия двух демонстрационных тестов. Добавлены идентификаторы
`direct` и `binary`. Для повторной проверки используются
`python -m pytest -v tests/test_pipeline_scenarios.py` и Flake8.
