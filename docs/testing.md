# План тестирования

Инструмент: pytest. Запуск: `python -m pytest`. Автозапуск: GitHub Actions (`.github/workflows/ci.yml`).

| № | Матрица | Ожидаемый результат | Тип теста |
|---|---------|--------------------|-----------|
| 1 | 3x3: 0 0 1 / 2 0 0 / 0 3 0 | 2, 1, 2, 2 | Нормальный |
| 2 | 2x2: 1 2 / 3 4 | 0, 0, 0, 0 | Без нулей |
| 3 | 3x3, все нули | 3, 3, 3, 3 | Полностью нулевая |
| 4 | 1x1: 0 | 0, 0, 0, 0 | Граничный |

Порядок результатов: выше главной, ниже главной, выше побочной, ниже побочной.
