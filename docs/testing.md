## Лабораторная работа № 4. Уровень 2

### План тестирования

Проверить все восемь функциональных модулей. Выполнить модульные и
интеграционные тесты, проверить ветви успеха и отказа, зафиксировать
дефекты и повторить проверки после исправлений.

| Модуль | Основные сценарии |
|---|---|
| `input_module.py` | Проверка формы, типов и конечности чисел |
| `matrix_zero_analyzer.py` | Подсчёт нулей в четырёх областях |
| `binary_transport.py` | Круговой обмен, проверка формата и лимита |
| `data_mapping.py` | Сопоставление полей и обработка отсутствующего ключа |
| `report.py` | Текст отчёта и заголовок с размером матрицы |
| `integration.py` | Прямой запуск и сообщение при ошибке |
| `binary_integration.py` | Обмен через файл и отказ при ошибке |
| `safe_integration.py` | Запуск в дочернем процессе, таймаут и ошибки |

### Методы белого ящика

Для покрытия решений проверены успешные и ошибочные ветви. Для
покрытия условий и их комбинаций взята проверка формы строки матрицы.
Условие A означает «строка не список», условие B — «длина не равна n».
Проверены список и кортеж правильной и неправильной длины. При A=True
оператор `or` завершает проверку досрочно, поэтому B вычисляется только
в случаях A=False.

### Интеграция и результаты

Прямой, бинарный и защищённый запуск вернули счётчики 5, 1, 4, 2 для
одной матрицы 4×4. Неквадратная матрица была отклонена до создания файла.
Проверены вывод демонстрационных запусков и сообщения об ошибках.

Дефект MZA-001 выявлен для NaN и обеих бесконечностей. После добавления
проверки конечности все три теста воспроизведения прошли.
[Баг-репорт MZA-001](bug_report_lr4.md)
