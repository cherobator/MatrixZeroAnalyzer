# Сравнение методов тестирования

| Метод | Преимущество | Ограничение | Когда применять |
|---|---|---|---|
| Эквивалентное разбиение | Сокращает число тестов за счёт группировки входов | Ошибка возможна внутри неправильно выбранного класса | Для допустимых и недопустимых форм матрицы и типов данных |
| Анализ граничных значений | Находит ошибки на порогах | Требует определить границы диапазона | Для минимальной размерности и предельного размера бинарной матрицы |
| Покрытие операторов | Показывает, какие участки кода выполнены | Выполненный оператор может работать неверно на другом входе | Для первой проверки каждого модуля |
| Покрытие решений | Проверяет оба исхода ветвления | Отдельные условия составного выражения могут остаться непроверенными | Для путей успеха и отказа валидации |
| Покрытие условий | Проверяет истинное и ложное значение каждого условия | Число проверенных комбинаций может быть меньше полного набора | Для составных проверок формы и типов |
| Комбинаторное покрытие условий | Позволяет увидеть влияние сочетаний входных признаков | Число сочетаний быстро растёт, часть вычислений пропускается из-за короткого замыкания | Для коротких составных проверок, например типа и длины строки матрицы |

В MatrixZeroAnalyzer модульные тесты проверяют правила отдельно,
интеграционные — передачу данных между модулями, регрессионные — защиту
от повторного появления MZA-001. Случай с NaN выявился после достижения
100% покрытия, когда в тесты добавили новый вход.
